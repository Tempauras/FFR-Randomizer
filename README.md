# FFR Randomizer

A mod for FINAL FANTASY RESONANCE that randomizes battle encounters from a seed. It currently covers the first area's `DT_01Gra_40_01_Encount` table.

- Each game launch creates a new seed.
- The same seed gives the same battle groups. The game still picks between those groups itself, so the order of fights can differ.
- Press **F9** in the field to show the seed panel. Use Ctrl+C and Ctrl+V in the text box, then **Apply seed**.

Battle groups come from a pool of ordinary fights. Enemies from the whole game can appear, with no level scaling, so early areas can be very difficult.

## Installing

You need [UE4SS](https://github.com/UE4SS-RE/RE-UE4SS) installed in the game, with BPModLoaderMod enabled. The DLL targets UE4SS commit `1ceefac8` and may not work with another build.

Download the release zip and extract it into the `FINAL FANTASY RESONANCE` game folder, which gives:

```text
FFRS/Content/Paks/LogicMods/FFRRandomizer.pak, .ucas, .utoc
FFRS/Binaries/Win64/ue4ss/Mods/FFRRandomizer/enabled.txt
FFRS/Binaries/Win64/ue4ss/Mods/FFRRandomizer/dlls/main.dll
```

## Building

The mod has two parts: a C++ DLL with the randomizer logic, and a Blueprint pak with the in-game panel.

Clone with submodules:

```bash
git clone --recurse-submodules <repository URL>
```

The nested UE4SS submodules use SSH addresses, so you need SSH keys set up on GitHub. UE4SS's own documentation also asks for an Epic account linked to GitHub.

### DLL

Requires Git, CMake, Rust and Visual Studio with the C++ tools.

```bash
cmake -S CppMods -B CppMods/build -G "Visual Studio 18 2026" -A x64
```

```bash
cmake --build CppMods/build --config Game__Shipping__Win64 --target FFRRandomizer
```

With Visual Studio 2022, use `"Visual Studio 17 2022"` instead. Copy the built `FFRRandomizer.dll` to `ue4ss/Mods/FFRRandomizer/dlls/main.dll` and add an empty `enabled.txt` in `ue4ss/Mods/FFRRandomizer`.

### UI pak

Requires Unreal Engine 5.6 and the C++ tools it uses to compile the editor tool. Close the editor, then run:

```bash
Tools\BuildUI.bat
```

It asks for the engine and game folders the first time, builds the pak into `Dist/FFRRandomizer` and installs it into the game. The panel's assets are generated by `Source/FFRSModTools`, so `Content/` isn't stored in the repository.
